レシピムービー帳 ／ 差別化の説明

競合は「動画を読まなくていいレシピ」に、
私たちは「動画を見ながら作れるレシピ」にする

マグネットレシピは、動画から材料と手順を取り出して文章のレシピに置き換えるアプリです。レシピムービー帳は、材料と手順を取り出すところまでは同じですが、動画を画面に残し、手順と動画の場面を結びつけます。このページでは、その違いを画面のイメージで説明します。

2つの考え方

競合（マグネットレシピ）

動画を文章に変換する

動画→材料・手順の文章→動画は見ない

保存したあとは文章のレシピが中心です。動画を見たいときは YouTube に移動します。

レシピムービー帳

動画と手順をセットで使う

動画＋材料・手順→手順から場面へ飛ぶ

アプリの中で動画を再生し、各手順に「何分何秒の場面か」を持たせます。文章で分かりにくいところは、その場で動画を見て確かめられます。

触って試す：手順をタップすると、その場面へ

下のスマホ画面の手順をタップするか、「次へ」を押してください。動画のバーがその手順の場面に移動します（動画はイメージです）。

オムライス（2人分）
玉ねぎをみじん切りにする
1:207:00

    この画面でできること

    • 動画は画面の上に固定され、手順を読んでいる間も見える
    • 今の手順がオレンジで強調され、どこまで進んだかが分かる
    • 手順をタップすると、動画がその場面から再生される
    • 「前へ／次へ」は大きめのボタンで、料理中の手でも押しやすい

    時間はどうやって入れるか

    • MVP：動画を見ながら「今の位置を記録」ボタンを押して入れる
    • 将来：動画をAIで解析し、手順と時間を自動で入れる（挑戦枠）

    実際のアプリでは YouTube の埋め込みプレーヤーを使います。再生や場面の移動では YouTube API の利用枠を消費しません。

    「卵で包む場面をもう一度見たい」とき

    料理中は、文章だけでは分かりにくい手つきを動画で確かめたくなります。そのときの操作を比べました。

    競合

    1. 「動画を見る」で YouTube アプリに移動する
    2. シークバーを動かして、卵で包む場面を探す
    3. 見終わったら、レシピアプリに戻る
    4. どの手順まで進んでいたかを探し直す

    4操作＋場面探し

    レシピムービー帳

    1. 手順「卵で包む」をタップする

    1操作。アプリから出ない

    競合から取り入れること・変えること

    競合の分かりやすい部分はそのまま取り入れ、動画まわりの使い勝手を変えます。

    機能方針内容
    URL を貼って登録取り入れるURL を貼ると、AI が概要欄から材料・人数・手順を取り出す
    買い物リスト取り入れるレシピを選び、人数を指定して追加する（献立の機能は作らない）
    動画の再生変えるYouTube に移動せず、アプリの中で再生する
    手順変える手順ごとに動画の時間を持たせ、タップでその場面に飛ぶ
    調理モード足す動画を固定し、今の手順を強調し、画面が消えないようにする
    買い物リストの内訳足す材料をタップすると、どのレシピでどれだけ使うかが分かる

    誰のための違いか

    文章だけだと「きつね色」や「とろみがつくまで」が分からない。動画で手つきを見ながら作りたい

    料理に慣れていない人ほど、文章より動画を頼りにします。競合が「動画を見なくても作れる」ことで時間を節約するのに対し、レシピムービー帳は「動画を見ながら迷わず作れる」ことで失敗を減らします。
